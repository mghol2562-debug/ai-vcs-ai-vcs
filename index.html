استوديو الفيديو بالذكاء الاصطناعي

اكتب مشهدك، ودع الذكاء الاصطناعي يكتب كود الفيديو وينفّذه.

هذا الموقع-website بإنشاء كامل الدردساوي

ما المشهد الذي تريده؟

أضف مؤثرات صوتية وأصوات شخصيات. سمِّ كل صوت باسم واضح (مثل: صوت رجل يصرخ)، ويضعه الذكاء الاصطناعي في اللقطة المناسبة.

مؤثرات مدمجة جاهزة (اضغط للتجربة): نقر، انتقال، صدمة، بهجة، تقوى وغيرها. يضعها الذكاء الاصطناعي تلقائياً في كل مشهد.

مواقع المؤثرات المجانية: freesound.org · pixabay.com/sound-effects · mixkit.co/free-sound-effects. حمّل الملف ثم أضفه هنا، وراجع رخصة كل ملف. وللأصوات الناطقة: أنشئها بأي أداة تحويل نص إلى صوت أو سجّل صوتك.

اختر خط النصوص التي تظهر داخل الفيديو.

حمّل خط ثمانية من صفحته الرسمية (يصلك الملف بالبريد)، ثم ارفع ملف OTF هنا. يبقى الملف على جهازك فقط ولا يُرفع لأي مكان، حسب رخصة الخط.


  






  
  

    

      
      
    

    

    

    

      
سكربت Python جاهز

      
  1. ثبّت: pip install pillow numpy arabic-reshaper python-bidi مع برنامج FFmpeg.
  2. نزّل السكربت باسم ai_vcs_video.py.
  3. شغّله: python ai_vcs_video.py فينتج ai_vcs_video.mp4 بالصورة والصوت. للتجربة السريعة أضف --preview، ولخط ثمانية أضف --font font.otf.
